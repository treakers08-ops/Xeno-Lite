# XenoLite - Full Gameplay Scripts (Cloud Build Ready)

This repo contains the full Xenoverse-style VR demo scripts and a GitHub Actions workflow to build an Android APK in the cloud.

## Steps (Chromebook-friendly)

1. Create a new GitHub repository and upload all files from this ZIP.
2. Add repository secrets: UNITY_EMAIL and UNITY_PASSWORD.
3. Push a commit or run workflow manually in GitHub Actions.
4. Download the APK artifact after the workflow finishes.
5. Install on Quest 2 using SideQuest Web.

Now the cloud build will produce a working VR fighting demo APK.
